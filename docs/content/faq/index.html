--- title: "FAQ" description: "Common questions about writing, sharing and printing notation on this site" ---

Questions about using the site and the library. For anything this page doesn't answer, ask on GitHub Discussions.

Writing notation

Where do I start?

The Quick Start walks through a first piece, and the tutorials go from there. To try things as you read, use the side-by-side playground: type on the left and press Render.

Is there a song close to mine I can start from?

The library has every song in notation_demos, by composer and by ragam. Each song page has "Open in playground", which opens it in the editor to change.

Does the playground keep my work?

It keeps a draft in this browser and opens it on your next visit. Nothing is stored on a server. Another browser or device won't see the draft, so share a link to move a piece between them.

Can I write an alapana or tanam with no tala?

Not yet. A \noTala command is planned, but every line still takes a cycle today.

Can I transcribe from a photo of a notebook?

The photo transcriber reads swaras from photos and PDFs. It calls Claude, so it needs your own Anthropic API key, and you check its result against the page.

Sharing, printing and saving

How do I share a piece with a student?

Press Share in the playground. For a library song you haven't changed, it gives that song's library page. Otherwise it gives a link that carries the notation itself, which opens on its own page with Print, SVG and PNG. The link is copied for you, and it also shows in the toolbar.

Who can read a link I share?

Anyone who has the link. The notation travels inside the link itself, after the #, and the site never receives or stores it. Share it as you would share the notation.

Can I print it, or save it as a PDF or an image?

Yes. Print / PDF prints the notation alone, scaled to the page, and "Save as PDF" in the print dialog gives a PDF. SVG and PNG save it as an image. All three are on the playgrounds and on a shared link's page.

Does it work on a phone?

A shared link's page is readable on a phone. A full cycle is wider than a phone screen, so each line scrolls sideways inside the notation. The playground's editor is easier to use on a larger screen.

Hearing it

Can I hear the notation played?

Not yet. The library already works out when each note sounds, in beats. Playing it, with the tala and a drone, is being built with thambura.

Using the library in your own site

Can I render notation in my own page or app?

Yes. Install the notations package from npm, then see the API documentation for parsing, rendering, printing and export.

Getting help

Where do I report a bug or ask for a feature?

Open an issue on GitHub Issues, with the notation source that shows the problem if you can.

Where do I ask a question?

On GitHub Discussions.
