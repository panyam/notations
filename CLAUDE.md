# notations

A TypeScript library that parses, models and lays out Carnatic music notation (`src/`), plus
its docs site with playgrounds and a photo transcriber (`docs/`). Start with `README.md`;
`docs/SUMMARY.md` covers the docs site; `NEXTSTEPS.md` says where each line of work stopped.

## Commands

```bash
pnpm install                 # pnpm version is pinned by sha512 in package.json's packageManager
pnpm test                    # jest, library and docs tests (docs/tests/)
pnpm run build               # typedoc, ESM + CJS, CSS, UMD
pnpm run check:esm && pnpm run lint
pnpm run spell               # cspell over docs/content; add domain words to cspell.config.yaml
pnpm run build:docs          # docs JS into docs/static/js/gen/
cd docs && make run          # docs site on http://localhost:8085/notations/
cd docs && make site         # production site and search index into docs/dist/docs, no deploy
pnpm run transcribe:photos   # photo transcriber CLI; needs ANTHROPIC_API_KEY
pnpm run exercise:48         # mission #48's exercise in headless Chromium; --base for a local site
pnpm run library             # song pages from notation_demos at docs/library.json's pin; --bump
```

The pre-commit hook runs clean, build, check:esm, lintfix and test. PRs merge with merge
commits, not squash.

PR screenshots go on the orphan `pr-assets` branch, one folder per PR (`pr54/`). Link them by
raw.githubusercontent URL pinned to the commit, since `gh` cannot upload images. Commit there
with `--no-verify`, because the hook builds code that branch does not have.

## Dependencies and supply chain

- `pnpm-workspace.yaml` turns on minimumReleaseAge (3 days), trustPolicy no-downgrade,
  blockExoticSubdeps and strictDepBuilds. An install that fails one names the package.
  Exclude the exact version with a comment saying why, never the whole package.
- Install scripts run only for packages listed `true` in `allowBuilds`.
- To re-resolve the lockfile from scratch, delete `node_modules` as well as
  `pnpm-lock.yaml`. pnpm otherwise reuses the old versions from `node_modules/.pnpm`.
- After a pull, if the hook's typedoc step fails with "linkify-it does not provide an export
  named 'default'", delete `node_modules` and run `pnpm install --frozen-lockfile` again.
- CI pins every action by commit SHA and runs `pnpm audit --prod`.
- Typedoc stays on minimatch 10 through a `typedoc>minimatch` override, so Dependabot alert 127
  is dismissed as tolerable. Recheck the override whenever typedoc is bumped.

## TypeScript and tests

- TypeScript is 6.0, not 7. typescript-eslint, ts-jest and typedoc do not run on 7 yet (#43).
- TS 6 loads no `@types` packages by default. `tsconfig.test.json` (jest) and
  `docs/tsconfig.json` list theirs. `docs/components/styles.d.ts` declares `.css`, `.scss`
  and `?url` imports.
- Layers: runtime (`notations/core`) < parser (takes an `EmbellishmentParser`) < Carnatic gamakas
  < `load()` < renderer < export (`notations/export`: print, SVG, PNG; never reaches `web/`).
  notations works in beats, never on a clock; playback belongs to thambura and the apps (#75).
  `src/tests/layers.spec.ts` enforces it; inside `src/`, never import from the package index
  (`"./"`). Details: `src/ARCHITECTURE.md` (#18, #74).
- Parser errors contract, galore tokenizer priorities and command validation:
  `src/ARCHITECTURE.md`. `load()` never throws; a new command reports bad params as errors.
- ts-jest compiles to CommonJS, so code that jest loads cannot use `import.meta`. For an
  asset URL in docs code, import `"file?url"`; webpack emits the file.
- `DockViewPlayground` is a `createDock` from `@panyam/tsappkit-dock`, which supports dockview-core
  4.13 to 8.x. On 8 the stylesheet comes from the `dockview` package (`dockview/dist/styles/dockview.css`).

## Docs site

- Deploys from `.github/workflows/docs.yml` after CI passes on master; `cd docs && make deploy`
  runs it by hand. The workflow builds master's tip and skips the deploy if master moved past
  the commit CI tested. Checking out `workflow_run.head_sha` there fails CodeQL
  (actions/cache-poisoning).
- `docs/templates/gen.*.html` are generated by `pnpm run build:docs` and committed. Their
  hashes change on every build.
- The docs server is s3gen (`docs/main.go`, Go 1.26). Change how it serves in s3gen
  (`~/newstack/s3gen/main`), then bump `docs/go.mod`. `Site.Serve` shuts down gracefully on
  SIGINT (v0.1.7), and a build copies `static/` into `dist/docs` (v0.1.8).
- `pnpm test` checks every docs example: it parses, no swaras run together (`SRG` is one note),
  and a named tala uses its standard cycle (`docs/tests/examples.spec.ts`). `links.spec.ts`
  checks internal links. Musical claims still need a musician (#72).
- Search is Pagefind over the built `dist/docs`, indexed by `make render` (CI runs it). `make run`
  has no index, so the search box says so. Test search on `make site` output served under
  `/notations/`.
- White header, footer and hero text sits on `--header-bg` and `--footer-bg`. Don't put it on
  `--primary-color`, which is light blue in dark mode (#65).
- The docs webpack config has no Node polyfills (`buffer: false`).
- Playwright's Firefox won't start on macOS 27 ("Could not find profile folder"). Run Firefox
  checks in the `mcr.microsoft.com/playwright:<version>-noble` image. Playwright's macOS WebKit
  doesn't scroll a focused box on arrow keys; real Safari does, so don't file that (#66).
- Restart `make run` after `pnpm run build:docs`. The running server keeps the old
  `gen.*.html` templates, and the page then 404s on the old bundle.
- Run Prettier on files by path. Running it over all of `docs/components` reformats unrelated
  files.
